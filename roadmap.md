# Roadmap

## What this is
A study task list for people learning a language. Each task is tagged with a language skill, so learners can see which skill they have been avoiding.

## What Done means
A stranger opens the live site, creates an account with an email and password, adds a few study tasks each tagged Reading, Writing, Listening, or Speaking, and checks some off as done. They see how many tasks they have finished in each skill, with the lowest one labeled "Least practiced." When they log back in later, everything is still there, and no other account can see their tasks.

## Slices
1. Sign up and log in | done-criteria: In a private window on the live site, click Sign up, enter a new fake email and a password, submit, and the page shows "Logged in as" with that email and a Log out button; click Log out and the page shows Log in and Sign up with no email; log in with that email and a wrong password and an error message appears while you stay logged out; log in with the correct password, close the tab, reopen the site, and you are still logged in as that email | status: ACTIVE
2. Add tasks that stay saved, each tagged with a skill | done-criteria: While logged in, type "Read one news article", pick Reading, click Add, and it appears in the list labeled Reading; refresh, log out, log back in, and the task is still there with the same label; log in as a second fake account and its list is empty and shows none of the first account's tasks; click Add with the task text empty and nothing is added and a message asks for task text | status: pending
3. Mark tasks done and see the least-practiced skill | done-criteria: Tick a task's checkbox and it shows as done, and is still done after a refresh; on a new account the summary shows all four skills with a done count of 0; finish two Reading tasks and one Writing task and the summary shows Reading 2, Writing 1, Listening 0, Speaking 0 with "Least practiced: Listening, Speaking"; finish one Listening task, refresh, and Listening shows 1 and "Least practiced" shows only Speaking | status: pending
